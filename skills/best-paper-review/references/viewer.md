# PDF 阅读器与批注查看器

技能有两种页面，共用同一份 `review.json`：

| 页面 | 命令 | 用途 |
| --- | --- | --- |
| **阅读器**（默认交付的 `review-viewer.html`） | `python3 scripts/package_viewer.py paper.pdf WORK/review.json out.html`（`finalize.py` 自动生成） | 只读。阅读审稿意见、核对原文、浏览论文速览；双击打开，离线可用 |
| **编辑器**（本地服务） | `python3 scripts/serve.py --pdf paper.pdf --review WORK/review.json` → http://127.0.0.1:8768 | 新建与编辑意见、框选与调整区域、撤销；“保存”写回 review.json（旧版本自动备份到 `.backups/`），保存后自动运行 `evidence.py`；只监听本机 |
| 编辑器单文件版 | `python3 scripts/package_viewer.py paper.pdf WORK/review.json out.html --editor` | 不开服务时编辑；修改需“导出 → 审稿 JSON” |

`serve.py --demo` 打开内置的合成示例（编辑器）。两种单文件页面都内含完整 PDF，分享前确认可以公开。

## 阅读器

- **布局**：顶栏只有标题、“审稿意见 / 论文速览”切换、总评分数、搜索、深色模式与菜单；左侧页面缩略图（彩色小点表示该页有哪类意见）；中间 PDF；右侧审稿面板（可拖动宽度）。缩放、页码与“高亮”开关在 PDF 底部的悬浮条上。
- **引文高亮**：每条意见的本文引文按归一化文字（只比较字母和数字，容忍连字与换行差异）在 PDF 文字层中定位，原句按意见类型着色（主要问题红、次要问题橙、待澄清紫、改进建议蓝、优点绿）；区域意见画虚线框。页面右侧对应高度有带编号的标记，悬停预览、点击打开意见。定位不到的引文（多为表格或公式中的文字）在详情中提示，并跳到所在页。
- **意见**：按类型分组，状态筛选与搜索；详情中正文自动分段（按论证步骤与 (1)(2) 编号），点击“原文证据”滚到原句并闪烁；J/K 切换上一条/下一条。另有“总评”（分数、子分、决定评分的意见、九维度）与“复核”标签页。
- **论文速览**（M 切换）：一句话概括、针对什么问题、所属研究脉络（复核归纳的上位问题）、相关前作（创新性检索读过的截止前前作，含共同点、差异与原文引文）、方法、贡献与作者原话（可定位，附创新性评级）、实验设置与核对过的数字、审稿核实。只用 `review.json` 已有字段，不增加审稿开销；审稿判断单独列在最后，不与作者的说法混在一起。速览模式下 PDF 上标出贡献原话（蓝）和数值核对的引文（青）。
- **排版**：中英文之间的空格统一为四分之一字宽的间隙；`$...$` 用 KaTeX 渲染，常见的纯文本公式（如 `Q_target`、`a′`、`≤`、`τ=0.005`）自动转为公式；中文引号用中文字体。
- **导出**：Markdown 审稿意见、审稿 JSON、论文速览（Markdown）。
- **快捷键**：`M` 切换视图；`J`/`K` 下一条/上一条；`Esc` 返回列表；`/` 搜索；`H` 显示/隐藏高亮；`[`/`]` 收起页面栏/审稿面板；`+`/`-`/`0` 缩放；`?` 帮助。

## 编辑器

- **浏览**：连续滚动、按需渲染（长论文也不卡）、缩放（适合宽度/百分比）、页码跳转、可拖动的侧栏宽度。
- **意见列表**：按主要问题、次要问题、待澄清的问题、改进建议、优点分组，默认收起，点击组标题展开，搜索或筛选时自动展开；卡片只显示标题与两行摘要；全文搜索，“筛选”按钮展开位置（全文/页级/区域/当前页）、状态、严重度、维度筛选。
- **阅读视图**：点击意见后审稿面板切换为该意见的完整内容（正文、证据、机制比较、反证检查、建议），同时在 PDF 上为它的每条本文引文加框高亮（标注“编号 · 引文 n”），页级意见在页面左侧加色条，PDF 滚动到区域框或第一条引文；全文意见跳到第一条可定位的引文；顶部可返回列表或切换上一条/下一条。
- **面板宽度**：拖动分隔条调整并记住宽度；“加宽审稿面板”按钮（W）把面板加宽到约 62% 窗口宽度。
- **证据核对**：每条引文旁显示 ✓（在对应版本快照中找到，页码一致）/ ✗（找不到或页码不符）/ ?（未加载快照）。“定位”按钮跳到引文并高亮。
- **新建与编辑**：＋全文、＋页级、框选区域（拖动鼠标）；在 PDF 上选中文字可“以选中文字新建意见”或“添加为当前意见的证据”。编辑器会实时核对引文，并拒绝不合规的“确认问题”（没有本文引文或反证检查）。选中的区域框可拖动移动，拖右下角调整大小。
- **总评卡片**：侧栏顶部显示分数、推荐、置信度和各类意见的数量条；点击“主要问题”“优点”等标签可快速筛选。
- **复核**：查看审稿意见复核（lint 与独立复核子代理）的每条意见及主审稿人的处理结果。
- **深色模式**：右上角月亮图标切换，偏好保存在浏览器中。
- **总评 / 维度 / 来源**：查看与编辑总评（分数下拉框使用目标会议量表）、九维度结论与说明、来源版本与日期核验情况。
- **撤销与草稿**：Ctrl+Z 撤销最近 60 步；修改会自动暂存在浏览器中，重新打开时提示恢复。
- **身份检查**：PDF 哈希或页数与审稿记录不一致时显示警告；哈希不一致时进入只读，避免区域错位。
- **提示注入**：快照中发现疑似注入文字时显示提醒。
- **导出**：审稿 JSON、中文 Markdown、带原生注释的 PDF（区域为矩形注释，页级为便签，全文意见放在首页左侧；原 PDF 不被修改，可在 Acrobat/Preview/Zotero 中查看）。

### 编辑器快捷键
`J`/`K` 下一条/上一条；`W` 加宽面板；`Esc` 从阅读视图返回列表；`N` 新建页级意见；`R` 框选；`E` 编辑；`Del` 删除；`/` 搜索；`+`/`-` 缩放；`Ctrl+S` 保存；`Ctrl+Z` 撤销；`Esc` 取消。

## 注意
- 区域坐标是相对显示页面（含页面自带旋转）的归一化 `[x, y, w, h]`。用 `find_quote.py --rect` 生成的坐标可以在查看器中微调。
- “✓”只表示引文存在于快照中，不代表结论正确。
- 单文件版内含整篇 PDF，分享前确认可以公开。
- 依赖：PDF.js 3.11.174（Apache-2.0）、pdf-lib 1.17.1（MIT），放在 `assets/templates/pdf_viewer/vendor/`；KaTeX 0.16（MIT）在 `assets/vendor/katex/`。都不需要联网。
